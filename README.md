# INVENTHOR Brain

INVENTHOR Brain is the central brain and mentor layer of the INVENTHOR system.

This repository stores shared system rules, modular architecture principles, approved learning, module memory, fix memory, templates, cleanup rules, and improvement logic used across INVENTHOR-powered applications.

Normal users cannot directly modify this brain. Updates are promoted only through owner-approved flows after private data filtering, validation, versioning, and rollback preparation.

Private user data, personal memories, tokens, archives, chats, photos, files, provider keys, and confidential records must never be stored in this repository.

The central brain is a federation catalog and shared constitution. Domain work is
owned by separate private repositories for architecture, design, visual, social,
language, automation, and continuation memory. See
`federation/BRAIN_REPOSITORY_CATALOG.yaml`.
